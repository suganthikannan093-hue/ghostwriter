# Product

- GhostWriter turns abandoned ideas and dead tech into Kiro-ready projects (Kiroween 2026, Resurrection category).

- Core loop: paste → resurrect → read spec → download zip → open in Kiro → run tasks.
- Tone: spooky but useful. Jokes live in copy (epitaphs), never in the generated code.
- Always keep a working offline demo mode for judges.
